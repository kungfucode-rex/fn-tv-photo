# FN Photo —— 飞牛相册的 Android TV 客户端（1.4.11：电视上出二维码，客人扫码发评论，评论以弹幕飘过）

FN Photo 是一个 Android TV 端的飞牛相册客户端，走的是飞牛相册自己的接口（不是把 NAS 当文件共享读），所以电视上看到的就是相册 App 里的那份内容。全程遥控器操作，免费开源，无广告无内购。本贴持续更新，最新版一直放在这里。

这一版是隔了几天的一大批改动，所以下面写得细一点 —— 最值得看的是**图评**。

## 新功能：图评（需要自己起一个服务端）

**一边放幻灯片、一边让屋里的人用手机往电视上发评论。** 预览照片时，照片角上会出现一张二维码；客人用微信扫一下，打开的网页上直接写评论（不用装 App、不用登录，名字可以留「匿名」），评论几秒后就以**弹幕**的形式从照片上飘过去。适合聚会、婚礼、生日、年会这种"照片在电视上放着、大家想说两句"的场合。

- **弹幕可调**：设置里有 `图评`（关 / 仅幻灯片 / 全部）、`图评服务器`、`图评连接状态`、`上传范围`、`弹幕`（关 / 少 / 多）、`有新评论时多停一会儿`。默认**只在幻灯片播放时**出现；想让翻页看照片时也出现，把 `图评` 改成「全部」。
- **此刻这一张也能单独管**：查看器角上多了一个 **图评** 按钮（在 原图 和 幻灯片 之间），按 OK 展开三行开关 —— 二维码、弹幕、弹幕数量 —— 管的是**眼前这一张**，不用回设置页。
- **一条评论最长 20 个字**：这不是随便定的，是按弹幕在 1080p 电视上真能放下的长度卡的（一行最多占屏宽 45%）。
- **手机上删掉的评论会从电视上消失**：网页端删掉一条，电视上正在飘的那条飘完这一趟就不再出现。管理员在手机网页上还能编辑、删除、审核、看举报。

### 图评服务端怎么起（NAS 上三分钟）

发布在 Docker Hub，**多架构**（amd64 / arm64 自动选），飞牛 **Docker 应用 → Compose → 新增项目**，把下面这段粘进去、把口令换成你自己的，点「启动」：

```yaml
services:
  tuping:
    image: "kungfucode/tuping:0.1.2"
    container_name: "tuping"
    restart: "unless-stopped"
    ports:
      - "8080:8080"
    volumes:
      - "./data:/data"
    environment:
      TUPING_ADMIN_TOKEN: "change-me"
```

然后电视上 **设置 → 图评服务器** 填 `这台 NAS 的地址:8080`（手机也要能打开这个地址），回去预览照片、按角上的「图评」，二维码就出来了。

几句话必须先说：

- **这个端口不要映射到公网。** 它是给局域网用的：评论对所有能连到它的人可见，没有账号体系，只有一个管理员口令（就是上面那个）。它默认说明文 HTTP，也能直接说 HTTPS（配证书即可，README 里有），但那保护的是路上那一段，边界不变。
- **评论存在 `./data` 目录里**，备份就是备这个目录。**换目录 = 评论全没了**（1.4.11 起电视会自己重新注册，不会卡在"这张照片不在图评里"）。
- **发评论有限流**：每个访客 5 条/分、每个 IP 30 条/分、每张图 200 条/小时，以及整个端点 120 条/分（最后这一道是 0.1.2 新加的）。被拦下会提示「发得太快了，歇一会儿」，等一分钟就好 —— 看到它是限流生效，不是坏了。
- 更细的部署说明（HTTPS、离线自建镜像、备份、排错表）在仓库 README 的「图评服务端」一节。

## 这一版还改了这些

- **文件夹可以切网格 / 列表**：标题右边的按钮写的是按下之后会变成什么；网格一眼看得出有几个文件夹、各是哪个，列表不截断、层级写在名字里。
- **幻灯片走得出第一页了**：过去放映只在前 60 张里循环（超过 60 张的相册播完就从头来），现在放映中会把后面的照片自己取回来。
- **幻灯片不再卡在慢照片上、也不会因为原图吃满内存崩掉**：等到忍耐上限就先把缩略图铺上，原图继续在后台下、到手原地换上去。
- **缓存里有原图就直接画原图**：默认「仅用于幻灯片播放」下手动翻页用缩略图，但只要原图已经在缓存里，翻过去就是原图。
- **扫码提示"这张照片不在图评里"修好了**：服务端重装/换数据目录之后，电视上那张旧码会自己作废并重新注册。
- 弹幕的字号、行数、速度重调过（原来一行一行叠在一起、字还大了一倍）。
- 信息条角上多了 **原图** 按钮（就这一张，现在看全画质）；设置页整列可滚动；深色/浅色主题；检测升级同时问 Gitee 与 GitHub。

安装（三种任选）：

1. 拷到 U 盘插到电视上，用电视自带的文件管理器点开安装（大部分电视要先在设置里允许「未知来源应用」）；
2. 用当贝市场 / 电视助手之类的「本地安装」功能；
3. 会用 adb 的话：`adb install -r FN-tvphoto-1.4.11.apk`

**从 1.3.7 直接覆盖安装即可，设置会保留**（包名没变）。首次打开填 NAS 地址，例如 `192.168.31.14:50317`（不写端口就按飞牛默认的 5667 走），再填飞牛的账号和密码。NAS 开了访问码，会多出一个访问码输入框。

**想用应用内升级**：Android 8 及以上还要在系统设置里允许本应用「安装未知应用」—— 检测升级那一行会提示并直接带你过去，只需要开一次。

## 注意事项

- 只读：浏览、看图、幻灯片、（新增的）图评没问题；删除、上传、重命名、收藏都还没有。大图页没有缩放和拖动。
- 飞牛相册的接口不是公开接口，官方一改就可能失效，到时候我尽量跟。
- 「检测升级」会联网，但**只在进设置页（或按 OK）时**，向 Gitee / GitHub 各发一次请求问最新是哪个版本；没有账号体系、没有埋点，除此之外不联系任何地方。
- 密码保存在 App 本地的 SharedPreferences 里（这套接口没有 refresh token 可用，只能这样），介意的别在 App 里存密码。
- 图评是**你自己的一台服务端**，评论只存在你自己的库；换地址或换数据目录就是从零开始。
- 内置音乐是四首商业录音，随 APK 公开分发有版权顾虑；要再分发建议自己替换成可自由使用的曲目（`app/src/main/assets/music/`）。
- 如果你装过更早的 `com.tvphoto`（1.2 之前的包名），对 Android 来说那是另一个应用，先卸载旧的，否则会有两个图标。
- 环境要求：Android 6.0（API 23）及以上，电视、盒子、投影都行；NAS 和电视在同一个局域网，相册服务已开启、账号能读到照片。「文件夹」读的是相册的托管文件夹，列表是空的话，去飞牛里把目录加进去就行。
