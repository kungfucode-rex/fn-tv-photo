# 飞牛相册上电视了：遥控器看照片、幻灯片配自己的音乐，客人扫码还能发弹幕

FN Photo 是一个 Android TV 端的飞牛相册客户端，走的是飞牛相册自己的接口（不是把 NAS 当文件共享读），所以电视上看到的就是相册 App 里的那份内容：时间线、相册、他人分享、人物、文件夹、Live Photo 和视频串流。全程遥控器操作，免费开源，无广告无内购。本贴持续更新，最新版一直放在这里。

**1.3.7 之后的每一版都在这一个包里了**，下面只说功能，怎么装、怎么用、每一版的改动都写在 README 里。

## 浏览

- **我的照片（时间线）**：一年一行，一行里排着这一年的各个月份 —— 月份在上、这个月第一张照片在下；左右走月份，上下换年份。
- **我的相册**：自己建的相册，带封面和照片 / 视频数量；**他人分享**单独一栏，卡片上写着是谁分享给你的。
- **人物**：相册自带的人脸识别结果，圆形头像；没开 AI 索引会直接说明原因，而不是给一个报错。
- **文件夹**：相册托管的文件夹，可以一层一层点进去，标题右边的按钮在**网格 / 列表**之间切换（网格一眼看得出有几个、各是哪个；列表不截断，层级写在名字里）。
- **进入即刷新**：切分区、打开网格时会重新核对一遍，别人刚分享的相册、刚上传的照片不用重启就会出现；核对失败也绝不会把屏幕上已有的内容顶掉。

## 看照片

- **大图查看器**：左右翻页、信息条、视频可拖动进度串流播放，Live Photo 播放动态部分。
- **翻页不黑屏**：按右键是排队而不是硬切 —— 下一张就绪之前当前这张一直留在屏幕上，右下角显示呼吸的箭头（按三下就是三个箭头）；**只有指针停下的那一张会被取回来**。
- **预览原图**（设置 → 通用，默认「仅用于幻灯片播放」）：手动翻页用大缩略图、幻灯片才取原图，更快更省流量；信息条会写明眼前这张是**原图**还是**缩略图**，是缩略图时角上多一个 **原图** 按钮，按下去文件由后层取回、原地换上去，**中间不黑屏**。
- 图片缓存上限 5 GB，LRU 自动清理（视频不落盘），设置里能看到已用量、也能一键清空。

## 幻灯片

- 间隔 3 / 5 / 8 / 15 / 30 秒，顺序或随机；**间隔、顺序、音乐都在查看器的控件条里调**，不用回设置页。
- **背景音乐**：随幻灯片开始、随幻灯片停止，可多选、循环播放。内置一首（打包在 APK 里，所以开场就是声音，不用等加载）。
- **自定义背景音乐**：内置那首之外可以放你自己的歌，**不用电脑、不用另装服务端**。查看器曲目列表最后一行「＋ 上传 / 管理背景音乐…」（或 设置 → 幻灯片设置）打开**上传页**：左边标题和二维码，右边一个带序号的列表。手机连同一个 Wi-Fi 扫码，打开网页选一首或多首 mp3 就传上去了，每传完一首列表最上面就多一行、边框闪两下。列表里 OK 选中 / 取消（选中的才会被播放），**长按**出「排序 / 删除」两个小按钮：排序态下 ↑↓ 把这首歌往上 / 往下挪一位，序号就是播放顺序，内置那首也能排、也能删（它的文件在 APK 里删不掉，所以删除只是从列表里去掉，页面上会多一行「恢复内置曲目」把它放回来）。传上去的歌存在电视的曲库目录里（页面最下方写着完整路径，用数据线或文件管理器把 mp3 拷进去也一样会出现），上限 1 GB、单个文件 40 MB。「清空我的音乐」只删这些拷贝。
- **聚会模式**：幻灯片每 30 秒重新读一次相册 —— 别人刚传进相册的照片会**自己加入轮播**（追加在末尾，不会打乱正在看的那张），被删掉的照片会自己退出，全程不用碰遥控器。

## 屏保相册（本次新增）

**设置 → 通用 → 屏保相册**：选一个相册（列表里是你所有的相册，包括别人分享给你的），然后**只要一段时间没人碰遥控器，电视就自己开始全屏循环播放这个相册**；按任意键或点一下屏幕，立刻回到刚才那一屏、刚才那张照片、刚才那个位置。被指定为屏保的相册，卡片角上会有一个「屏保」角标，所以「我到底选了哪个」不用去设置里翻。

## 图评：电视上出二维码，客人扫码发评论，评论以弹幕飘过（需要自己起一个服务端）

**一边放幻灯片、一边让屋里的人用手机往电视上发评论。** 照片角上出现一张二维码，客人用微信扫一下，打开的网页上直接写评论（不用装 App、不用登录，名字可以留「匿名」），评论几秒后就以**弹幕**的形式从照片上飘过去。适合聚会、婚礼、生日、年会这种「照片在电视上放着、大家想说两句」的场合 —— **屏保相册放起来的时候，弹幕一样在飘。**

- **弹幕可调**：设置里有 `图评`（关 / 仅幻灯片 / 全部）、`图评服务器`、`图评连接状态`、`上传范围`、`弹幕`（关 / 少 / 多）、`有新评论时多停一会儿`。默认**只在幻灯片播放时**出现；想让翻页看照片时也出现，把 `图评` 改成「全部」。
- **此刻这一张也能单独管**：查看器角上有一个 **图评** 按钮（在 原图 和 幻灯片 之间），按 OK 展开三行开关 —— 二维码、弹幕、弹幕数量 —— 管的是**眼前这一张**。
- **手机上删掉的评论会从电视上消失**：网页端删掉一条，电视上正在飘的那条飘完这一趟就不再出现。管理员在手机网页上还能编辑、删除、审核、看举报。
- 服务端发布在 Docker Hub（多架构），飞牛 **Docker 应用 → Compose** 粘一段配置、起一个容器就行，端口映射到局域网、**不要映射到公网**。部署、HTTPS、备份、限流的说明都在仓库 README 的「图评服务端」一节。

## 其它

- **检测升级**：进设置页会自己查一次，按 OK 再查一次；查到新版本就下载，下完先校验 SHA-256、再校验 APK 签名和本应用是不是同一把，两样都过才交给系统安装器。**Gitee 和 GitHub 两个来源同时问**，取更新的那个。任何一步走不通，那一行都会把原因写出来 —— 电视上没有控制台，这是唯一能把它读出来的地方。有新版本时主菜单「设置」上会有一个红点，不用先打开设置页才知道。
- **登录一次就够**：登录信息按「服务器 + 账号」分别记住，下次开机自动登录；登录界面有历史账号，按一下就能填。**登录状态过期会自己恢复**：电视放着不动很久、NAS 把会话收回之后，重试会像重新登录一样重建会话，不用退出再登一次。
- **只走 HTTPS**：NAS 的自签证书首次使用时信任，证书换了会提示；NAS 开了访问码，会自动多出访问码输入框。
- **深色 / 浅色主题**可切换并记住（分别在明亮房间和昏暗房间里看的两种需要）。
- 退出照片会回到网格里的那一张，退出网格会回到那个月；设置页能看到「上次崩溃」—— 电视上没控制台，出错时至少有个能读的东西。

## 怎么装

**附件里的就是最新版**（1.5.7，15.8 MiB）。也可以从发布页下 —— 下面两个网址要**去掉中间的空格**再访问（论坛会把用户名里连在一起的字母打码，拆开写才能正常显示）：

- Gitee（国内快，应用内升级也用这个）：`https://gitee.com/kung fu code/fn-tv-photo/releases/latest`
- GitHub：`https://github.com/kung fu code-rex/fn-tv-photo/releases/latest`

安装（三种任选）：

1. 拷到 U 盘插到电视上，用电视自带的文件管理器点开安装（大部分电视要先在设置里允许「未知来源应用」）；
2. 用当贝市场 / 电视助手之类的「本地安装」功能；
3. 会用 adb 的话：`adb install -r FN-tvphoto-1.5.7.apk`

**从 1.3.7 直接覆盖安装即可，设置会保留**（包名没变）。首次打开填 NAS 地址，例如 `192.168.31.14:50317`（不写端口就按飞牛默认的 5667 走），再填飞牛的账号和密码。NAS 开了访问码，会多出一个访问码输入框。

**想用应用内升级**：Android 8 及以上还要在系统设置里允许本应用「安装未知应用」—— 检测升级那一行会提示并直接带你过去，只需要开一次。

手机也能装，装完有正常图标，不过界面还是强制横屏的遥控器布局，主要是给自己排查问题用的。

## 注意事项

- 只读：浏览、看图、幻灯片、图评都没问题；删除、上传照片、重命名、收藏还没有。大图页没有缩放和拖动。
- 飞牛相册的接口不是公开接口，官方一改就可能失效，到时候我尽量跟。
- 「检测升级」会联网，但**只在进设置页（或按 OK）时**，向 Gitee / GitHub 各发一次请求问最新是哪个版本；没有账号体系、没有埋点，除此之外不联系任何地方。
- 密码保存在 App 本地的 SharedPreferences 里（这套接口没有 refresh token 可用，只能这样），介意的别在 App 里存密码。
- 图评是**你自己的一台服务端**，评论只存在你自己的库里；换地址或换数据目录就是从零开始。
- 环境要求：Android 6.0（API 23）及以上，电视、盒子、投影都行；NAS 和电视在同一个局域网，相册服务已开启、账号能读到照片。「文件夹」读的是相册的托管文件夹，列表是空的话，去飞牛里把目录加进去就行。
