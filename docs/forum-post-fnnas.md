# FN Photo —— 飞牛相册的 Android TV 客户端（开源 / 遥控器操作 / 幻灯片带背景音乐）

一直想要一个能在电视上看飞牛相册的东西，没等到，就自己做了一个。

FN Photo 是一个 Android TV 端的飞牛相册客户端，走的是飞牛相册自己的接口（不是把 NAS 当文件共享读），所以电视上看到的就是相册 App 里的那份内容。全程遥控器操作，免费开源，无广告无内购。本贴持续更新，最新版一直放在这里。

## 浏览

- **我的照片（时间线）**：一年一行，一行里排着这一年的各个月份 —— 月份在上、这个月第一张照片在下；左右走月份，上下换年份，十年的照片几行就看完。
- **我的相册**：自己建的相册，带封面和照片 / 视频数量，点进去就是照片网格，Live Photo 有「动图」角标。
- **他人分享**：家里人共享给你的相册单独一栏，卡片上写着是谁分享的。
- **人物**：相册自带的人脸识别结果，圆形头像；隐藏的人脸不显示，没开 AI 索引会直接说明原因，而不是给一个报错。
- **文件夹**：相册托管的文件夹，可以一层一层点进去。

## 看照片

- **大图查看器**：左右翻页、上滑出信息条；视频能拖动进度串流播放，Live Photo 播放动态部分。
- **翻页不黑屏**：按右键不是硬切而是排队 —— 下一张就绪之前，当前这张一直留在屏幕上，右下角显示呼吸的箭头（按了三下就是三个箭头）。**只有指针停下的那一张会被取回来**：连按三次右键 = 三个箭头 + 第 3 张，中间两张既不上屏也不下载。
- **预览画质可选**（设置 → 预览原图，默认「仅用于幻灯片播放」）：手动翻页用服务端 1920px 的大缩略图，幻灯片才去取原图。信息条里会写明眼前这张是原图还是缩略图；是缩略图时角上多一个「原图」按钮，按下去文件由后层悄悄取回、原地换上去，**中间不黑屏** —— 这是「就这一张，现在要看全画质」，不改设置。
- **预加载与缓存**：从当前这张开始往后预热 50 张；图片缓存上限 5 GB，LRU 自动清理，视频不落盘。

## 幻灯片

- 间隔 3 / 5 / 8 / 15 / 30 秒，顺序或随机，可选内置的背景音乐（四首、可多选、循环，和幻灯片一起开始、一起结束）。间隔、顺序、音乐都在查看器的控件条里调，不必回设置页。
- **聚会模式**：幻灯片每 30 秒重新读一次相册 —— 别人刚传进相册的照片会自己进轮播，被删掉的照片会自己退出，全程不用碰遥控器。

## 其它

- **检测升级**（设置 → 检测升级）：进这一页会自己查一次，按 OK 再查一次；查到新版本就下载，下完先校验 SHA-256、再校验 APK 签名和应用是不是同一把，两样都过才交给系统安装器。Gitee 和 GitHub 两个来源同时问，谁先答用谁、取更新的那个。任何一步走不通，那一行都会把原因写出来 —— 电视上没有控制台，这是唯一能把它读出来的地方。
- **登录一次就够**：登录信息按「服务器 + 账号」分别记住（一台 NAS 上的多个账号各存各的），下次开机自动登录；登录界面有历史账号，按一下就能填。
- **只走 HTTPS**：NAS 的自签证书首次使用时信任，证书换了会提示；NAS 开了访问码，会自动多出访问码输入框。
- 深色 / 浅色主题可切换并记住；退出照片会回到网格里的那一张，退出网格会回到那个月。
- 设置页能看到「上次崩溃」—— 电视上没控制台，出错时至少有个能读的东西。
- 安装包 25.6 MiB，背景音乐是打包在里面的（四首 14 MB）。

## 怎么装

**附件里的就是最新版**（1.3.7，25.6 MiB）。也可以从发布页下 —— 下面两个网址要**去掉中间的空格**再访问（论坛会把用户名里连在一起的字母打码，拆开写才能正常显示）：

- Gitee（国内快，应用内升级也用这个）：`https://gitee.com/kung fu code/fn-tv-photo/releases/latest`
- GitHub：`https://github.com/kung fu code-rex/fn-tv-photo/releases/latest`

| | |
| --- | --- |
| 文件名 | `FN-tvphoto-1.3.7.apk` |
| 大小 | 26,817,782 字节（25.6 MiB） |
| 包名 | `com.kung fu code.fntvphoto`（去掉空格） |

安装（三种任选）：

1. 拷到 U 盘插到电视上，用电视自带的文件管理器点开安装（大部分电视要先在设置里允许「未知来源应用」）；
2. 用当贝市场 / 电视助手之类的「本地安装」功能；
3. 会用 adb 的话：`adb install -r FN-tvphoto-1.3.7.apk`

首次打开填 NAS 地址，例如 `192.168.31.14:50317`（不写端口就按飞牛默认的 5667 走），再填飞牛的账号和密码。NAS 开了访问码，会多出一个访问码输入框。

【图 6：登录页】

**想用应用内升级**：Android 8 及以上还要在系统设置里允许本应用「安装未知应用」—— 检测升级那一行会提示并直接带你过去，只需要开一次。

手机也能装，装完有正常图标，不过界面还是强制横屏的遥控器布局，主要是给自己排查问题用的。

## 注意事项

- 只读：浏览、看图、幻灯片没问题；删除、上传、重命名、收藏都还没有。大图页没有缩放和拖动。
- 飞牛相册的接口不是公开接口，官方一改就可能失效，到时候我尽量跟。
- 「检测升级」会联网，但**只在进设置页（或按 OK）时**，向 Gitee / GitHub 各发一次请求问最新是哪个版本；没有账号体系、没有埋点，除此之外不联系任何地方。
- 密码保存在 App 本地的 SharedPreferences 里（这套接口没有 refresh token 可用，只能这样），介意的别在 App 里存密码。
- 内置音乐是四首商业录音，随 APK 公开分发有版权顾虑；要再分发建议自己替换成可自由使用的曲目（`app/src/main/assets/music/`）。
- 如果你装过更早的 `com.tvphoto`（1.2 之前的包名），对 Android 来说那是另一个应用，先卸载旧的，否则会有两个图标。
- 环境要求：Android 6.0（API 23）及以上，电视、盒子、投影都行；NAS 和电视在同一个局域网，相册服务已开启、账号能读到照片。「文件夹」读的是相册的托管文件夹，列表是空的话，去飞牛里把目录加进去就行。
